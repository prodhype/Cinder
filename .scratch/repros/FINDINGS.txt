Cinder soundness audit — verified 2026-07-28
============================================

A1 Aggregate cast (check+emit-c OK, C fails)
  File: a1_aggregate_cast.ci
  Emits: b = ((B)(a));  — illegal C aggregate cast
  Clang: "used type 'B' where arithmetic or pointer type is required"

A2 type_key collision (check OK; unprefixed emit produces bad C)
  Files: a2_typekey_collision.ci, a2_list_collision.ci
  Root: type_key(*i32) == type_key(struct ptr_i32) == "ptr_i32"
  CLI `cinder emit-c path` module-prefixes user types and masks this.
  Unprefixed Compiler.compile_source collapses both generic specializations
  / List helpers to one C symbol → incompatible-pointer / member errors.
  See: a2_noprefix.c, a2_list_noprefix.c

B1 Match owning-payload transfer (check+emit-c+build OK, runtime UB)
  Files: b1_match_list.ci (exit 251 / abort), b1_match_result.ci (same),
         b1_match_class.ci (prints "drop 5" twice — double __del__)
  Contrast: b1_value_rejected.ci — `return o.value` correctly rejected C263,
  but `return v` from `case Some(v)` is accepted and double-frees.
  Lowered pattern in b1_match_list.c:
    const CinderList_i32 v = match.data.value;
    ... = v;
    CinderOption_list_i32_drop(&o);  // frees same buffer
    return ...;
